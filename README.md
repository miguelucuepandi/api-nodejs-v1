# API Balta.io

API Node.js desenvolvida durante o curso da Balta.io

## 🚀 Sobre o Projeto

Este projeto é uma aplicação backend construída com Node.js que segue os princípios SOLID e boas práticas de desenvolvimento.

## 📋 Pré-requisitos

- Node.js (v14 ou superior)
- npm ou yarn
- Banco de dados (conforme configurado)

## 🔧 Instalação

```bash
npm install
```

## ▶️ Executar o Projeto

```bash
npm start
```

## 🛠️ Tecnologias Utilizadas

- Node.js
- Express
- Banco de dados
- Outras dependências (confira package.json)
